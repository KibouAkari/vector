# Vector

**A private AI workspace for reliable, cost-aware and
secure autonomous work.**

Vector is an evolving AI platform built with Next.js,
PostgreSQL and Redis.

It combines AI chat, projects, artifacts, model
connections, usage reporting, infrastructure inspection,
permissions and background task execution.

> **Status:** Active development.
> This repository contains an application source snapshot,
> not the complete production deployment.

## Interface

Vector uses a quiet technical design with dark surfaces,
precise typography and subtle mint accents.

The login experience features a custom cinematic
black-hole renderer.

Screenshots will be added to
[docs/screenshots](docs/screenshots/README.md)
after privacy review.

## Current foundation

| Component | Purpose |
| --- | --- |
| Next.js / React | Web application and APIs |
| PostgreSQL | Persistent application data |
| Redis | Coordination and runtime state |
| Model modules | Model and provider management |
| Agent runtime | Multi-step task execution |
| Workflow runtime | Structured operations |
| Artifact runtime | Document and file workflows |
| Privacy and approvals | Controlled access and actions |

These are existing application areas, not a claim that
every planned feature is already complete.
