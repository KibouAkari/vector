# Product screenshots

The README gallery uses these genuine product captures:

- `vector-login.png` — cinematic login screen.
- `vector-dashboard.png` — workspace dashboard.

Before adding or replacing captures, redact real names, addresses, internal infrastructure, identifiers, API details, financial information and private project content. Never include credentials, customer data, private chat messages or server logs, and do not present mockups as application screenshots.

## Operations source captures

`vector-operations-overview.png`, `vector-operations-chat.png` and `vector-brain.png`
are browser captures of the real Next.js application using an isolated PostgreSQL
fixture and a synthetic Demo account. Usage values, account names and content are
synthetic. They show source UI behavior, not production activity, model quality or
live infrastructure. No paid provider was called and no target was scanned.
